# Architecture decision records

An ADR records a decision that binds future work. Write one when an architectural decision
would otherwise live only in a {{HOST_PR_ABBR}} discussion; keep the context, alternatives
and consequences next to the decision.

Name records `NNNN-slug.md`, using the next sequential four-digit number. Start with the
[template](0001-template.md). Its status line is **Proposed**, **Accepted** or **Superseded**;
a superseded record links to its replacement rather than silently changing the old decision.
